# Viola cybersecurity thesis — company profiles in focus

Three profiles Viola is actively looking for (per Or, 2026-07-03):

1. **Build-to-secure** — help organizations *operate* more securely by design. Example: checking LLM-generated code for cloud misconfigurations, then flagging and fixing them autonomously. (AI-generated code explodes the volume of insecure-by-default infrastructure — securing the build pipeline itself.)

2. **Mitigating the human factor** — companies that reduce the human element as the attack surface (social engineering, phishing, identity misuse, human error). *(Or wrote "migrating the human factor" — interpreted as "mitigating"; correct me if the thesis is actually about replacing/removing humans from workflows entirely.)*

3. **Risk remediation at scale** — help companies withstand the increasing **volume and complexity** of attacks: prioritizing and autonomously remediating exposures rather than just detecting them.

## Use

- Weekly digest: score cybersecurity items against these profiles; profile-matching startups get flagged explicitly ("fits thesis #1").
- DD: when a cyber company enters DD, state which profile it maps to (or that it maps to none — also a finding).
